# 第二阶段实验计划：领域辅助效果的确认性验证（E9–E11）

版本：2026-10-25，修订 1。作者：导师审查（supervisor review）。状态：**预注册**。本文件与 `01_configs/05_confirm_clinc.yaml`、`06_confirm_massive.yaml`、`07_massive_base.yaml` 一起，构成第二阶段的预注册方案，以合并这些文件的提交为准。合并之后，任何改动都必须写进第 11 节的修订记录，并且必须在相应的 test 评估之前完成。

## 1. 背景与动机

第一阶段（E0–E8）在 CLINC150 test 上一次性评估的结果是：

| 指标（test，3 个种子平均） | BERT-CE | BERT-Dom (λ=0.1) | 差值 |
|---|---|---|---|
| macro-F1 | 0.9593 | 0.9610 | +0.17 pp，三个种子分别为 +0.29 / +0.13 / +0.09 |
| 跨领域错误率 | 1.78% | 1.62% | −0.16 pp |
| 同领域错误率 | 2.28% | 2.27% | ≈0 |

这个结果有三个不足：

1. **只有 3 个种子**。差值在种子间的标准差约 0.10 pp，按种子做配对检验 p≈0.1。原来的 bootstrap 区间只对 test 样本重抽样，没有包含训练的随机性。
2. **验证集上的方向相反**：CE 0.9657，λ=0.1 0.9656。
3. **CLINC150 的 test 已经用过一次**。在同一份 test 上继续实验，只能算复现，不能算独立确认。

所以第二阶段的目标是：**用更多种子和一份没有使用过的外部数据集，按事先固定的分析方案，确认或否定「领域辅助监督能提升意图分类，并且是通过减少跨领域错误实现的」。**

## 2. 研究问题与假设

| 编号 | 假设 | 角色 | 数据 |
|---|---|---|---|
| **H1** | BERT-Dom（λ=0.1）的 macro-F1 高于 BERT-CE | **主假设（确认性）** | MASSIVE en-US test（E10） |
| **H2** | BERT-Dom 的跨领域错误率低于 BERT-CE（机制假设） | 主要次级假设 | MASSIVE en-US test（E10） |
| H1-R / H2-R | 同 H1 / H2 | 复现（次级） | CLINC150 test，10 个种子（E9） |
| H3 | 领域辅助对 OOS 检测（AUROC_OOS、FPR@95%IS-TPR，MSP 和 Mahalanobis 两种检测器）的影响 | 描述性，不做确认性结论 | CLINC150 test（E9） |

同领域错误率在所有研究中都作为描述性指标报告。

## 4. 数据

### 4.1 CLINC150（E9、E11）
与第一阶段相同：`clinc/oos-eval@828f809`，使用 `data_full.json`。数据的 content hash 记录在 `07_metadata/data_manifest.json` 中。

### 4.2 MASSIVE 1.1 en-US（E10）
- **来源**：<https://amazon-massive-nlu-dataset.s3.amazonaws.com/amazon-massive-dataset-1.1.tar.gz>，许可为 CC BY 4.0。
- **固定版本**（S10 会校验，不一致就报错）：
  - 压缩包 SHA-256：`4cba5faa11c71437928e17cb1b9b3d8b8e727e7ea363a3a9a8045e19c0491577`
  - `1.1/data/en-US.jsonl` 的 content SHA-256：`c70f75c6a543a26e249ec383df67733ad9b1066f6c0406c2e04a3f03356e407e`
- **规模**：train 11,514 条，dev（作为 val）2,033 条，test 2,974 条；60 个意图，18 个场景，每个意图只属于一个场景。
- **映射规则**：场景（scenario）作为领域；`utt` 原文不做任何处理；`partition=dev` 对应 val。MASSIVE 没有 OOS 类，所以 E10 只评估意图分类。
- **类别缺失**：val 中缺少 `audio_volume_other`，test 中缺少 `cooking_query`。**macro-F1 在被评估的那份数据中实际出现的意图上取平均**，所以 MASSIVE test 上是 59 个意图；预测为缺失意图的样本仍然算作错误。CLINC 的 150 个意图都会出现，所以这条规则与第一阶段的定义等价。早停所用的 val macro-F1 沿用训练代码中的定义（对 60 类取平均，缺失的那一类恒为 0）。两种定义只相差一个固定的倍数（59/60），不影响 checkpoint 的选择。
- **重复与不平衡**：有 88 条文本在数据中重复出现，各意图的样本数也不平衡（train 中每个意图 4–810 条）。两者都保持原状，在报告中说明即可。

## 5. 统计分析方案（预注册）

**主要指标**：macro-F1（按第 4.2 节的规则计算）。**机制指标**：跨领域错误率 = count(domain(pred) ≠ domain(gold)) / N。

**分析单位**：一对运行（CE_s, Dom_s），两者共用同一种子 s 的初始权重和样本顺序。

1. **种子层面**：对每个种子 s 在完整 test 上计算 Δ_s = Dom_s − CE_s，然后报告：
   - 均值、标准差、中位数、Δ>0 的种子个数；
   - Wilcoxon 符号秩检验（双侧，精确 p 值）；
   - 单样本 t 检验（双侧），作为补充。
2. **两层 bootstrap**（共 2000 次，种子 `20261025`）：每次先有放回地重抽 10 对种子，再在每个意图内部有放回地重抽 test 样本，保持各意图的原样本数；然后计算重抽后的平均 Δ。区间取 2.5% 和 97.5% 分位数。这个区间**同时包含了训练随机性和 test 抽样波动**。
3. **判定规则**（H1：越高越好；H2：越低越好）：
   - **支持**：两层 bootstrap 的 95% 区间**整体落在有利的一侧**，**并且** Wilcoxon p < 0.05；
   - **反驳**：区间整体落在不利的一侧，并且 p < 0.05；
   - **其余情况一律判为「不确定」**，不得表述为「两者等价」。
4. **最小有意义差值（SESOI）**：macro-F1 提升 0.2 pp。判定为「支持」但均值低于 0.2 pp 时，报告为「统计上可检出，但实际幅度很小」。
5. **多重比较**：唯一的确认性检验是 E10 的 H1。H2 和 E9 是预先指定的次级分析，在 α=0.05 下单独报告，不做校正，也不能单独作为主结论。H3 只做描述。
6. **OOS（H3，只在 E9 中）**：对每个运行，用其 `train_features.npz` 重新拟合 Mahalanobis（只用 train 的 in-scope 样本，方法与 S05 相同），同时计算 MSP。报告 AUROC_OOS 和 FPR@95%IS-TPR，**都不依赖阈值**。区间用两层 bootstrap 计算（1000 次，IS 样本按意图分层，OOS 样本整体有放回地重抽）。
7. **无论结果如何都要完整报告**，包括判定为「不确定」或「反驳」的情况。

**统计功效的粗略估计**：按第一阶段的种子间标准差（约 0.10 pp）估算，10 个种子的标准误约为 0.033 pp，可以检出约 0.1 pp 量级的差值。MASSIVE 的种子方差事先未知，如果明显偏大，就如实报告「不确定」，**不得追加种子**。

## 10. 报告口径（根据 E10 的判定结果）

- **H1 支持，且均值 ≥ 0.2 pp**：「在未使用过的外部数据集上，领域辅助监督带来了稳定且有实际意义的 macro-F1 提升」，并结合 H2 的结论说明作用机制。
- **H1 支持，但均值 < 0.2 pp**：「提升可以被统计检出，但幅度很小」。
- **H1 不确定**：「没有足够证据表明领域辅助能提升意图分类」。同时报告区间，说明能排除多大的效应。
- **H1 反驳**：如实报告「领域辅助在 MASSIVE 上降低了性能」，并讨论两个数据集的差异（例如领域数和类别平衡程度）。
- E9 的结论一律加上前缀「在已经使用过一次的 CLINC test 上复现」。H3 只描述数值，不给出结论。
