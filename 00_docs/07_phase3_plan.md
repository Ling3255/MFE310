# 第三阶段实验计划：监督对比学习对意图表示与 OOS 检测的影响（E12–E15）

版本：2026-10-25，修订 2。作者：导师审查。状态：**计划草案，导师确认后冻结**。代码按第 9 节另行实现；代码合并之后，本计划才成为预注册版本。

修订 2 取代修订 1 的草案。修订 1 原计划以 BANKING77-OOS 作为外部确认数据，按导师要求改为**只使用 CLINC150**，研究主题也改为 CE 与 CE + 监督对比学习的比较。

## 1. 背景与动机

| 前两个阶段的结论 | 证据 |
|---|---|
| 领域辅助（λ=0.1）不能可靠地提升意图分类 | 第二阶段 E10（MASSIVE，10 个种子）：Δ = −0.30 pp，判定为「不确定」；第一阶段 CLINC 上的 +0.17 pp 在 10 个种子下缩小到 +0.02 pp |
| 唯一稳定的正向信号：领域辅助让 **Mahalanobis** 的 AUROC_OOS 略有提升 | 第二阶段 E9：+0.075 pp，10/10 个种子为正。按预注册只作为描述性结果 |
| Mahalanobis 明显优于 MSP | 两个阶段都成立（FPR95 约 0.11 对比约 0.17） |

第二阶段的信号提示了一个机制：**辅助监督改善了 CLS 特征空间的结构，而 Mahalanobis 依赖的正是这种结构**。领域辅助只是间接地影响这个结构；**监督对比学习（SCL）则直接以「同类聚拢、异类分开」为目标**。所以第三阶段的核心问题是：

> **在 CLINC150 上，交叉熵加监督对比学习（CE+SCL）的 BERT，能否比只用交叉熵（CE）的 BERT 学到更有利于 OOS 检测的意图表示，同时不损害意图分类？**

另外设一个可选分支，与本项目最初的「领域」主题衔接：**层级对比学习**（同一意图为强正例，同一领域为弱正例）。

## 2. 文献依据（已核实）

| 文献 | 与本计划相关的结论 |
|---|---|
| Gunel et al., ICLR 2021，*Supervised Contrastive Learning for Pre-trained Language Model Fine-tuning* | 损失为 CE + SCL。在 RoBERTa-Large 少样本 GLUE 上提升明显（N=20 时 QNLI 从 65.0 提高到 75.7），**N=1000 时几乎没有提升**（SST-2 从 94.0 到 94.1）。所以在全量数据下，本项目对**意图分类**提升的预期很低 |
| Zeng et al., ACL 2021，*Modeling Discriminative Representations for OOD Detection with Supervised Contrastive Learning* | **使用 CLINC-Full 和 CLINC-Small**。在 BERT + GDA（即 Mahalanobis）上，SCL+CE 相比 CE：OOD 召回 64.24 → 66.84，OOD F1 66.17 → 68.03，IND 准确率 88.13 → 88.97，类内方差下降。他们采用先用 SCL 预训练、再用 CE 微调的两阶段训练，并加入对抗数据增强 |
| Zhou, Liu, Chen, EMNLP 2021，*Contrastive OOD Detection for Pretrained Transformers* | 对比学习（尤其是带 margin 的）让表示更紧凑，配合 Mahalanobis 能大幅改善 OOD 检测。但实验数据集不是 CLINC |
| Podolskiy et al., AAAI 2021 | Mahalanobis 在 Transformer 意图 OOD 检测中显著优于其他方法，本项目的结果与此一致 |
| Uppaal et al., ACL 2023 | 基于距离的方法（Mahalanobis、KNN）稳定优于基于输出的方法（MSP、Energy） |

**对本项目的预期**：OOS 检测（Mahalanobis）方面，有直接在 CLINC 上的先例，属于有依据的假设；意图分类方面，在全量数据下预期提升很小，所以只做**非劣效**检验。

## 3. 数据：只使用 CLINC150，并且不再使用官方 test

CLINC 的官方 `test` 和 `oos_test` 已经用过两次（E6、E9）；CLINC 的各个数据变体（full、small、imbalanced、oos_plus）都共用同一份 val 和 test，所以 CLINC 内部不存在新的官方 test。第三阶段按下面的方式构造**从未被用于任何评估的数据**：

| 用途 | 构成 | 条数 | 是否用过 |
|---|---|---|---|
| **训练集 T3** | CLINC `train` 去掉内部 test 后剩下的部分（每个意图 80 条） | 12,000 | 前两个阶段的模型在这部分上训练过（第三阶段的模型重新训练，不复用旧模型） |
| **内部 IS test（IHT）** | 从 CLINC `train` 中按固定种子 `20261026`、在每个意图内随机抽出 20 条；先剔除与 val/test 重复或存在标签冲突的文本 | 3,000 | **从未被用于评估**；第三阶段的模型不在它上面训练 |
| **内部 OOS test** | CLINC `data_full` 的 `oos_train`（100 条）加上 `data_oos_plus` 独有的 OOS 语句（151 条） | **251** | **从未被任何阶段使用过**（第一、二阶段的 CE 训练和检测器拟合都只用 in-scope 数据）；与所有其他划分零重叠（已核实） |
| 验证集 | CLINC `val`（3,000）和 `oos_val`（100） | — | 用于早停、开发阶段选参数和选阈值。与前两个阶段相同 |

**披露事项**：IHT 的文本曾被第一、二阶段的模型用于训练，但从未用于评估；第三阶段的模型从零开始训练，看不到 IHT。官方 test **不使用**。如果导师之后希望和文献的数字做对照，可以另行批准在官方 test 上做一次描述性评估（属于第三次使用，必须披露），但它不参与任何结论。

## 4. 实验组

| 组 | 损失 | 说明 |
|---|---|---|
| **A：CE** | L = CE | 基线 |
| **B：CE+SCL** | L = (1−λ)·CE + λ·SCL（Gunel 的形式） | **主方法**。SCL 作用在 **L2 归一化的原始 CLS 特征**上，也就是 Mahalanobis 使用的同一份特征；温度为 τ |
| C：CE+HSCL（可选） | L = (1−λ)·CE + λ·HSCL | 层级对比：同一意图的正例权重为 1，同一领域、不同意图的正例权重为 w = 0.5（固定，不调）。λ 和 τ 沿用 B 选出的值 |

**三组共同的设置**（预注册）：
- 模型：bert-base-uncased（固定 revision）；领域头关闭（λ_domain = 0）；lr 2e-5，5 个 epoch，patience 2，warmup 10%，max_length 64；其余设置与 `01_base.yaml` 相同。
- **batch 设置**：batch 为 32，不做梯度累积；采用**按类别采样**，每个 batch 包含 8 个意图、每个意图 4 条，保证 SCL 在 batch 内有足够的正例。**A 组使用完全相同的采样方式**，使三组之间唯一的差别是损失函数。
- 采用联合训练，即 CE 和 SCL 同时优化。Zeng 等人的两阶段训练和对抗增强**不纳入**本计划，以控制工作量；报告中要说明这一差异。

## 5. 开发阶段（E12–E13）：只用 val

| 步骤 | 内容 | 训练次数（种子 100–102） |
|---|---|---|
| E12 | A，以及 B 的 6 组超参数：λ ∈ {0.1, 0.3, 0.5} × τ ∈ {0.1, 0.3} | 3 + 18 = 21 |
| E13 | C（使用 B 选出的 λ 和 τ） | 3 |

**B 的选择规则（预注册）**：在 val 上，Mahalanobis 的 AUROC_OOS 三个种子平均最高的那组（val 的 IS 3,000 条对 `oos_val` 100 条）；同时要求 val macro-F1 不低于 A 超过 0.3 pp。平局时取较小的 λ。如果没有任何一组满足条件，**H7 和 H8 就不进行**，并如实报告。

选出的超参数必须**写入第 11 节并提交**，之后才能开始确认阶段的训练。

## 6. 确认阶段（E14–E15）：内部 test

- **训练**：A、B（以及 C，如果做的话）各 10 个种子（0–9），同一种子共用同一份初始权重和同一采样顺序（沿用第一、二阶段的配对机制）。
- **评估**：IHT（3,000 条）加上内部 OOS test（251 条），**每组只评估一次**，需导师在 GitHub 上批准后进行。

### 假设（预注册）
| 编号 | 内容 | 主要指标 | 角色 |
|---|---|---|---|
| **H7** | B 的 OOS 检测优于 A | Mahalanobis 的 **FPR@95%IS-TPR**（越低越好） | 主要 |
| **H8** | B 的意图分类不差于 A | IHT 上的 macro-F1，非劣效界限为 **−0.3 pp** | 主要 |
| H9 | C 的 OOS 检测优于 A；C 的跨领域错误率低于 A | 同 H7；跨领域错误率 | 次级，只做描述 |
| — | AUROC_OOS，以及 MSP、KNN 打分下的 FPR95；B 相对 A 的 macro-F1 是否更高 | — | 描述性 |

**最小有意义差值（SESOI）**：FPR95 降低 **1.0 pp**。

## 7. 统计分析（沿用第二阶段的 M12）

- **配对单位**：同一种子下的 (A_s, B_s)。
- **种子层面**：计算 Δ_s，做精确 Wilcoxon 检验（双侧，枚举全部符号组合）。
- **两层 bootstrap**（2000 次）：重抽种子对；IHT 在每个意图内部分层重抽；内部 OOS test 整体有放回重抽。
- **多重比较**：H7 和 H8 两项主检验采用 Bonferroni 校正，每项 α = 0.025，区间取 **97.5%**。
- **H7 判定**：97.5% 区间整体小于 0，**并且** Wilcoxon p < 0.025，才算「支持」。
- **H8 判定**：Δmacro-F1 的 97.5% 区间下界大于 −0.3 pp，即判定为非劣效。
- 「不确定」不得解释为等价；所有结果都要报告，包括开发阶段淘汰的超参数组合。

**功效说明**：内部 OOS test 只有 251 条，FPR95 的最小粒度约为 0.4 pp，区间会比较宽。如果效应小于 1–2 pp，很可能判为「不确定」。这是只用 CLINC 必须付出的代价，导师确认计划时请知悉。
