# AI 使用声明

本项目使用 Kimi Code CLI 辅助阅读实施计划、生成和修改 Python/Shell 代码、配置及说明文档，并辅助解释测试失败和整理验证结果。

核验方式包括：人工审查关键实验协议、自动化单元测试、真实 CLINC150 数据计数与映射断言、tiny-BERT 前向/反向/恢复测试、词法基线验证和冻结门禁检查。实际完成的检查以变更记录和运行产物为准。

AI 未被视为实验结果的作者或独立验证者。生成代码仍需项目成员审查；所有正式训练、test 指标、图表和结论必须以真实运行产物为依据。不得由 AI 补造实验数值、导师确认、队友贡献、引用或伦理审批。

最终提交前，项目成员应补充本声明的实际使用范围、人工修改及任何其他 AI 工具。
