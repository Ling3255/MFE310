# Domain-Aware Sampling 与监督对比学习后续实验计划

版本：2026-10-25，修订 1。状态：**计划草案，待导师确认；本文件不构成运行授权**。本计划只描述后续研究设计，不包含实现代码或实验结果。

## 1. 背景与研究动机

第三阶段比较了 BERT-CE 与 BERT-CE+SCL。结果表明，SCL 保持了意图分类的非劣效性，但没有足够证据表明它能改善 Mahalanobis OOS 检测。当前实现只按 Intent 构造 batch：同一 Intent 为正例，不同 Intent 为负例。虽然同领域困难负例可能自然出现，但采样器并未显式保证其比例。

本实验检验一个更具体的机制：**提高同领域、不同 Intent 的困难负例比例，是否能让 SCL 更有效地减少跨领域混淆？**

核心问题不是继续调整 λ，而是区分以下两种影响：

1. Domain-Aware Sampling 本身是否改变模型；
2. 在相同 Domain-Aware Sampling 下，加入 SupCon 是否仍有额外收益。

## 2. 研究问题与假设

| 编号 | 内容 | 角色 |
|---|---|---|
| H1 | Domain-Aware Sampling + CE+SupCon 的 Macro-F1 高于 Domain-Aware Sampling + CE | 主要比较 |
| H2 | 前者的跨领域错误率低于后者 | 机制比较 |
| H3 | 上述差异与同领域困难负例学习有关 | 通过同领域混淆、领域 F1 和案例解释，不作单独因果证明 |
| H4 | OOS FPR95 和 OOS False Acceptance 也得到改善 | 辅助、描述性，不作为推进或主结论依据 |

主要对照为 **B vs C**。A 组仅用于与原方法比较，不能单独证明 SupCon 的作用，因为 A 与 C 同时改变了采样器和损失。

## 3. 实验组

| 组 | Sampling | Loss | 用途 |
|---|---|---|---|
| A：现有 SCL | 原有 Intent-only class-balanced sampling | `(1−λ)·CE + λ·SupCon` | 原方法参照；第三阶段已有结果可复用 |
| B：采样对照 | Domain-Aware Sampling | 仅 CE | 排除采样策略本身的影响 |
| C：改进模型 | 与 B 完全相同的 Domain-Aware Sampling | 与 A 相同的 `(1−λ)·CE + λ·SupCon` | 检验采样与损失的联合改进 |

B 和 C 必须使用相同的初始权重、batch 顺序、训练预算和 checkpoint 选择规则。A 与 B/C 的比较只作辅助描述。

## 4. 固定实现约定

### 4.1 Step 1：现有实现核对

实施前只读核对并记录：

- batch 中 Intent/Domain 的构成；
- 正负样本构造和 SupCon 的数学定义；
- SCL 是否作用于 L2 归一化的原始 CLS；
- 是否已有显式的同领域困难负例采样；
- 初始权重、sampler generator 和样本顺序哈希。

本计划不要求修改 SupCon 公式。若实际实现与本文件描述不一致，应先报告并暂停，不根据结果临时改设计。

### 4.2 Step 2：Domain-Aware Sampling

每个 batch 固定为 32 条：

```text
2 个 Domain × 4 个 Intent × 每个 Intent 4 条样本 = 32 条
```

要求：

- Domain 标签只来自官方 `domains.json`；MASSIVE 不纳入本实验。
- 每个 batch 的 Domain 和 Intent 由固定种子 sampler 决定，B 与 C 完全一致。
- 同一 batch 内同时存在同领域、不同 Intent 的困难负例。
- 不根据验证或 test 结果调整 Domain/Intent 的抽取方式。
- 采样导致的分布变化由 B 组单独估计，不把 A vs C 的全部差异归因于 SupCon。
- λ 固定为 0.5，τ 固定为 0.1，与第三阶段选定值一致；本实验不重新搜索。
- 保持原有 SupCon Loss、有效 batch size、优化器、学习率、warmup、max_length、early stopping 和 checkpoint 规则。

## 5. 数据与使用历史

只使用 CLINC150 及其既有第三阶段固定划分：

| 用途 | 数据 | 数量 |
|---|---|---:|
| 10-shot 训练 | 每个 Intent 10 条 | 1,500 |
| 25-shot 训练 | 每个 Intent 25 条 | 3,750 |
| 80-shot 参考 | 每个 Intent 80 条 | 12,000 |
| 验证 | CLINC val + oos_val | 3,000 + 100 |
| IS 评估 | 第三阶段 IHT | 3,000 |
| OOS 评估 | 第三阶段 OOS-251 | 251 |

固定规则：

- 不使用 CLINC 官方 test 或 oos_test。
- 10-shot、25-shot 和 80-shot 的采样种子沿用第三阶段划分，不重新抽取或挑选文本。
- IHT 不参与第三阶段或本实验训练。
- 所有评估均使用相同的数据、预处理、checkpoint 和推理精度。

**披露**：IHT 和 OOS-251 已在第三阶段正式评估中使用过。本实验属于后续探索或重复评估，不声称是完全独立、从未接触的 test。若未来需要正式确认，必须在本计划经导师批准并冻结后，把该历史写入结果与报告。

## 6. 分阶段执行

### 6.1 阶段 D1：10-shot 主比较

- A 可复用第三阶段已有的同设置结果，不为了本实验重复训练 A。
- B、C 各使用固定的 seeds `{0,1,2,3,4}` 训练，共 10 次新运行。
- 保持第三阶段低资源训练预算（包括 epoch 上限和 early stopping）。
- 完成后先保存全部运行，再计算指标；不得删除异常种子或只保留有利结果。

### 6.2 阶段 D2：25-shot 条件验证

只有 D1 同时满足以下推进条件时才运行 D2：

1. B vs C 的 Macro-F1 平均配对差值大于 0，且两层配对 bootstrap 的 95% 区间整体大于 0；
2. B vs C 的跨领域错误率平均差值小于 0，且其 95% 区间整体小于 0；
3. 没有未解释的实现错误、缺失运行或数据哈希异常。

不满足时停止扩展，报告 10-shot 的不确定或负结果，不通过更换 λ、采样器或种子继续寻找收益。

D2 使用与 D1 相同的 seeds 和协议，B、C 共 10 次新运行。D2 的结果用于判断 10-shot 的方向是否延续，不作为事后选择最好数据规模的依据。

### 6.3 阶段 D3：80-shot 描述性参考

第三阶段的 80-shot A 结果作为高数据量参考，解释 SCL 在数据充足时收益是否减弱。现有结果不包含同设置的 Domain-Aware B/C，因此不得把不同采样条件下的差异写成严格的 B vs C 因果比较；如需新增 80-shot 对照，必须另写修订计划并在任何新评估之前冻结。

## 7. 指标与错误分析

### 7.1 预先指定的指标

| 指标 | 用途 |
|---|---|
| Macro-F1 | D1/D2 的主要分类指标，按评估数据中实际出现的 Intent 计算 |
| Accuracy | 辅助分类指标 |
| Cross-domain Error | 主要机制指标：`count(domain(pred) != domain(gold)) / N` |
| Within-domain Error | 检查是否以同领域混淆增加为代价 |
| Per-domain intent F1 | 检查收益集中于哪些领域 |
| 同领域 Intent 混淆对 | 检查困难负例学习是否真正减少近义混淆 |
| OOS FPR95（IS positive） | 辅助 OOS 指标，越低越好 |
| OOS False Acceptance | 辅助部署指标，使用既有 val 阈值，不在 test 上重选 |

不得用 OOS 辅助指标替代 Macro-F1 的主要结论。不得只报告有利的领域、种子或数据规模。

### 7.2 定性分析

固定分析种子，从 B 错/C 对和 B 对/C 错的样本中分别抽取案例，重点检查：

- 同领域近义 Intent 混淆；
- 跨领域混淆；
- 领域辅助是否过度强化粗粒度区分；
- OOS 误接纳和 IS 误拒的语言线索。

所有案例保留真实标签、两臂预测、领域、分数和人工解释。解释只针对具体样本，不作为普遍因果证明。

## 8. 统计分析

- 配对单位：同一种子的 `(B_s, C_s)`，差值定义为 `C_s − B_s`。
- 报告每个种子的原始指标、均值、样本标准差（ddof=1）和配对差值。
- 两层配对 bootstrap：重抽种子对；IS 按 Intent 分层重抽；OOS 整体重抽。D1/D2 使用相同抽样规则和分析种子。
- 区间同时反映种子变异和 test 样本抽样波动，不包含超参数选择、历史 test 暴露或未来重训的全部不确定性。
- 精确 Wilcoxon 作为辅助描述。由于只有 5 个种子，不把 `p < 0.05` 设为推进条件，也不把不显著解释为等价。
- 主要推进判断使用第 6.2 节的预先固定规则；不得在看到结果后更换区间、种子或主要指标。

## 9. 结果解释口径

| 结果 | 报告方式 |
|---|---|
| D1 满足推进条件，D2 方向也成立 | Domain-Aware Sampling 与 SupCon 的组合在低资源设置下显示出一致收益，并伴随跨领域错误减少 |
| D1 满足但 D2 不延续 | 收益可能依赖特定训练规模，不能声称稳定改进 |
| D1 区间跨 0 | 证据不足，不进入 D2，不把结果写成 SupCon 无效或两臂等价 |
| 跨领域错误减少但 Macro-F1 不改善 | 可能存在粗粒度与细粒度区分的权衡，不宣称整体性能改善 |
| OOS 与分类方向不一致 | 分类与拒识可能有不同表示需求，不声称二者同时改善 |

任何结果都不追加种子、调 λ、改采样规则或重复 test 以寻找有利结论。

## 10. 风险与限制

- Domain-Aware Sampling 同时改变 batch 的领域分布，因此必须保留 B 组，不能只做 A vs C。
- 同领域困难负例增加可能提高跨领域区分，也可能增加同领域细粒度混淆。
- 10-shot/25-shot 只有 5 个种子，统计功效有限；OOS-251 也会使 OOS 区间较宽。
- IHT 曾被旧模型用于训练，新实验虽然重新训练模型，但仍需披露文本历史。
- 当前设计检验的是采样与 SupCon 的组合，不证明所有对比学习方法都有效或无效。
- 第三阶段的不同训练协议和文献中的两阶段/增强方法不能直接作为本实验的等价复现。
